# CCFOLIA 채팅 로그 에디터

CCFOLIA 채팅 로그를 불러와서 편집하고, 꾸며서 HTML로 내보내는 도구입니다.

---

## 1. 불러오기

**"불러오기"** 탭에서 파일을 드래그하거나 클릭해서 선택합니다. 지원하는 파일:

- CCFOLIA에서 내보낸 원본 `.html` 로그 파일
- 이 에디터에서 다운로드했던 `.html` 파일 (다시 불러와서 이어서 편집 가능)
- `.json` 로그 파일 (CCFOLIA Log Exporter로 추출한 파일)

파일을 불러오면 요약 정보와 탭 목록이 표시됩니다. **"불러오기 완료"** 버튼을 누르면 출력 화면으로 이동합니다.

---

## 2. 편집

왼쪽 목록에서 전체 로그를 확인하고 수정할 수 있습니다.

- **검색**: 상단 검색창에 이름이나 메시지 내용을 입력하면 해당 항목만 걸러서 보여줍니다.
- **편집(✏️)**: 메시지 내용을 직접 수정합니다. 저장/취소 버튼으로 확정합니다.
- **숨기기(🚫)**: 해당 메시지를 출력에서 제외합니다 (완전 삭제가 아니라 다시 표시로 되돌릴 수 있음).
- **삭제(🗑)**: 해당 메시지를 목록에서 완전히 제거합니다.

편집한 내용은 자동으로 출력 미리보기에 반영됩니다.

---

## 3. 출력

**"출력"** 탭에서 최종 결과물을 꾸미고 내보냅니다. 왼쪽은 설정, 오른쪽은 실시간 미리보기입니다.

### 출력 설정
- **타이틀**: 결과물 상단에 표시될 제목 (시나리오 제목 등)
- **테마**: 기본(다크) / 라이트 / 소설풍 / 미니멀 중 선택
- **출력할 탭 선택**: 칩을 눌러 특정 탭(메인, 정보, 비밀 대화 등)만 켜거나 끌 수 있습니다.
- **표시 옵션**: 탭 이름 / 캐릭터 이미지 / 날짜 표시 여부를 각각 켜고 끌 수 있습니다.

### 탭 배경색
각 탭(메인, 정보 등)마다 배경색을 따로 지정할 수 있습니다. 체크박스로 켜고, 색상 피커나 헥스 코드 입력으로 원하는 색을 지정합니다. 끄면 테마의 기본 카드 색으로 돌아갑니다.

### 캐릭터 색상
캐릭터별로 이름 색상을 지정합니다. 기본값은 CCFOLIA 원본 색상이며, 체크박스를 켜면 원하는 색으로 바꿀 수 있습니다. 끄면 원본 색상으로 돌아갑니다.

### 캐릭터 이미지
캐릭터별 이미지를 지정합니다. 체크박스를 켜면 입력한 URL이 그 캐릭터의 모든 메시지에 일괄 적용됩니다. 끄면 각 메시지마다 원래 있던 이미지(있는 경우)를 그대로 사용합니다.

### 미리보기 검색
미리보기 상단의 검색창에 입력하면 일치하는 메시지만 걸러서 보여줍니다 (편집 탭 검색과 동일한 방식).

### 내보내기
- **⬇ HTML 다운로드**: 완성된 결과를 `.html` 파일로 저장합니다.
- **📋 HTML 복사**: 클립보드에 HTML 코드를 복사합니다.

다운로드한 `.html` 파일은 그대로 브라우저에서 열어볼 수 있고, **이 에디터에 다시 불러오면 그때까지의 모든 설정과 편집 내용이 그대로 복원**됩니다.

---

## 참고
- 화면 크기가 좁다면 편집 탭 왼쪽 목록과 출력 탭의 사이드바 경계를 드래그해서 너비를 조절할 수 있습니다.
